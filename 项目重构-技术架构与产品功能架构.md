# ALMT重构项目 - 技术架构与产品功能架构

> 版本: V1.0 | 日期: 2026-08-13

---

## 一、项目背景

### 1.1 现有系统

**ALMT (Asset Liability Management Tool)** 是一款银行资产负债管理桌面应用，采用C# + Excel VBA混合架构：

- **C# (WinForms/SunnyUI)**：负责UI、流程控制、数据管理
- **Excel VBA**：负责核心ALM计算逻辑
- **SQLite**：本地数据库存储

### 1.2 重构目标

将桌面应用重构为 **前后端分离的Web系统**，支持多用户并发访问，实现银行资产负债管理的数字化、智能化。

### 3.2 功能详细说明

#### 3.2.1 系统管理模块 (Sys)

| 功能 | 说明 |
|------|------|
| 用户管理 | 用户增删改查、密码重置 |
| 角色管理 | 角色定义、权限分配 |
| 权限管理 | 细粒度功能权限控制 |
| 操作日志 | 记录用户操作行为 |
| 系统配置 | 系统参数设置 |

#### 3.2.2 基础参数模块 (Base)

| 功能 | 说明 |
|------|------|
| 账户册管理 | 维护银行科目层级结构（树形） |
| 账户册属性 | 配置各账户的重定价频率、收益率曲线等 |
| 税率假设 | 配置各业务类型的税率 |
| 指标口径 | 定义利息净收入、生息资产等指标的计算口径 |
| 报表规则 | 配置输出报表的格式和规则 |

#### 3.2.3 业务参数模块 (Param)

| 功能 | 说明 |
|------|------|
| 利率情景假设 | 配置利率曲线和24个月情景预测 |
| 对客定价策略 | 配置各账户册的定价规则 |
| 风险权重 | 配置资产风险权重（RWA计算） |
| FTP利差 | 配置内部资金转移定价利差 |
| 业务计划 | 配置未来24个月的余额/日均计划 |

#### 3.2.4 数据管理模块 (Data)

| 功能 | 说明 |
|------|------|
| 存量数据导入 | Excel批量导入当前持仓数据 |
| 存量数据编辑 | 手动编辑/修改存量数据 |
| 数据校验 | 业务规则校验（完整性、一致性） |
| 历史版本 | 保留历史数据快照 |

#### 3.2.5 计算执行模块 (Calculate)

| 功能 | 说明 |
|------|------|
| 参数加载 | 将参数写入Excel模板 |
| 计算执行 | 调用Excel VBA宏执行计算 |
| 进度展示 | 实时展示计算进度（WebSocket） |
| 任务管理 | 查看历史计算任务状态 |
| 结果提取 | 从Excel提取计算结果到数据库 |

#### 3.2.6 结果展示模块 (Results)

## 四、数据库设计

### 4.1 核心表结构

```sql
-- 账户册体系
CREATE TABLE almt_coa_info (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    order_number VARCHAR(50),
    parent_coa_cd VARCHAR(50),
    coa_cd VARCHAR(50) NOT NULL,
    coa_name VARCHAR(200),
    leaf_desc VARCHAR(200),
    leaf_flag CHAR(1),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 账户册属性
CREATE TABLE almt_coa_attribute (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    coa_cd VARCHAR(50) NOT NULL,
    coa_name VARCHAR(200),
    term VARCHAR(50),
    accrule_base VARCHAR(50),
    curve_name VARCHAR(100),
    curve_id VARCHAR(50),
    business_line VARCHAR(100),
    float_ratio DECIMAL(10,4),
    replace_type VARCHAR(50),
    reprice_freq VARCHAR(50)
);

-- 存量数据
CREATE TABLE almt_current_position (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    coa_lvl VARCHAR(50),
    coa_name VARCHAR(200),
    balance DECIMAL(20,2),
    `average` DECIMAL(20,2),
    rate DECIMAL(10,6),
    current1~current72 DECIMAL(20,2),  -- 72个月数据列
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 利率情景假设
CREATE TABLE almt_param_rate_scenario (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    order_number VARCHAR(50),
    curve_name VARCHAR(100),
    curve_id VARCHAR(50),
    current_curve_value DECIMAL(10,6),
    scenario_M1~M24 DECIMAL(10,6)
);

-- 风险权重
CREATE TABLE almt_param_risk_weight (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    coa_cd VARCHAR(50),
    coa_name VARCHAR(200),
    weight DECIMAL(10,6)
);

-- 业务计划
CREATE TABLE almt_param_business_plan (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    coa_lvl VARCHAR(50),
    coa_cd VARCHAR(50),
    coa_name VARCHAR(200),
    plan_balance1~24 DECIMAL(20,2),
    plan_average1~24 DECIMAL(20,2)
);

-- 计算结果 - 指标
CREATE TABLE almt_result_index (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    index_code VARCHAR(50),
    index_name VARCHAR(200),
    F1~F27 VARCHAR(100),  -- 27个指标列
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 计算结果 - 策略
CREATE TABLE almt_result_plan (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    plan_code VARCHAR(50),
    plan_name VARCHAR(200),
    F1~F33 VARCHAR(100),  -- 33个策略列
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 计算任务
CREATE TABLE almt_calculate_task (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    task_id VARCHAR(36) NOT NULL UNIQUE,
    data_date DATE,
    status VARCHAR(20),  -- pending/running/completed/failed
    progress INT,
    error_message TEXT,
    started_at DATETIME,
    completed_at DATETIME,
    created_by BIGINT
);
```
